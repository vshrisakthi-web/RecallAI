## Design system (shared context — include with every prompt)

> Product: **RecallAI**, a privacy-first personal AI memory assistant.
> Style: clean, calm, trustworthy, modern SaaS dashboard. Light theme with one
> confident accent color (e.g., indigo/blue). Generous whitespace, rounded cards,
> subtle shadows. Typography: a clear sans-serif (e.g., Inter). Icons: simple line
> icons. The overall feel should communicate **privacy, trust, and clarity** — never
> "surveillance." Reuse one consistent component set (nav, cards, badges, buttons)
> across all screens.

## Task 1.3 — Overview dashboard

**Status:** 🟡 Prompt ready — design **pending** external generation.

```
Design the "Overview" landing screen for RecallAI, a privacy-first personal AI
memory assistant web dashboard (React + TypeScript, desktop-first, light theme,
clean modern SaaS style, indigo accent, Inter font, rounded cards, subtle shadows).

Layout — a persistent left sidebar navigation plus a main content area:

SIDEBAR (consistent app navigation, reused across all dashboard screens):
- Brand: "RecallAI" logo/wordmark at the top.
- Nav items with icons: Overview (active), Memory Timeline, Ask RecallAI,
  Privacy Settings.
- A persistent footer chip: "🔒 Data stored locally" (privacy indicator).

MAIN CONTENT — Overview:
1. Page header: "Overview" title + a CAPTURE STATUS badge on the right showing
   "Active" (green) with a small pause/stop control. (Also show it can read
   "Paused" amber or "Stopped" grey.)
2. Row of MEMORY ACTIVITY SUMMARY stat cards (3–4): Total Memories, Captured This
   Week, Sources Connected, and Last Capture time. Each card: icon, big number,
   small label.
3. "RECENT MEMORIES" section: a list/grid of the most recent memory cards. Each
   card shows: title, one-line preview, a SOURCE badge (e.g., "Article", "Link",
   "Note") with its icon, the source domain, the capture date, and a small "local"
   privacy indicator dot. Clicking a card opens its detail view.
4. A SEARCH entry point: a prominent search bar under the header with placeholder
   "Search your memories…" — it is the main way into the Memory Timeline.
5. QUICK ACCESS to Ask RecallAI: a clear primary button/card labeled
   "Ask RecallAI →" that jumps to the Q&A screen.

FOOTER / GLOBAL: a slim privacy strip reiterating "Your memories never leave this
device." Keep source references and privacy indicators clearly visible.

Include a populated state (real-looking mock data). Show it is responsive from
desktop to tablet width. Do not add login, ads, or cloud/sync elements — this is a
local-first, single-user tool.
```

**Export needed:** PNG/screenshot (desktop width) + optional tablet width. Save to
`docs/designs/overview/` and share with the agent for Task 1.9.
