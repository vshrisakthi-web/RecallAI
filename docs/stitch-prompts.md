# RecallAI — Google Stitch Design Prompts

**Module 1 — Design prompts for Google Stitch (external tool)**

> **How to use this file:** each section is a ready-to-paste prompt for
> [Google Stitch](https://stitch.withgoogle.com). Google Stitch is an **external**
> design tool that is **not** accessible from this coding environment, so the agent
> can only *write the prompt* — it **cannot** generate or export the design.
>
> **Workflow for each design task:**
> 1. Copy the prompt below into Google Stitch and generate the design.
> 2. Export the design (screenshot / PNG / Figma) and drop the file into
>    `docs/designs/<screen>/`.
> 3. Reply with the export so the agent can use it as the visual reference for
>    implementation (Task 1.9).
>
> **Status:** 🟡 Prompts written by the agent; the actual designs are **PENDING
> external generation** by the user. No design has been generated by the agent, and
> none is claimed to exist. See §"Pending designs" at the bottom.

---

## Design system (shared context — include with every prompt)

> Product: **RecallAI**, a privacy-first personal AI memory assistant.
> Style: clean, calm, trustworthy, modern SaaS dashboard. Light theme with one
> confident accent color (e.g., indigo/blue). Generous whitespace, rounded cards,
> subtle shadows. Typography: a clear sans-serif (e.g., Inter). Icons: simple line
> icons. The overall feel should communicate **privacy, trust, and clarity** — never
> "surveillance." Reuse one consistent component set (nav, cards, badges, buttons)
> across all screens.
